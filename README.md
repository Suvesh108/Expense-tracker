# 💰 ExTrack

ExTrack is a premium, minimalist Single Page Application (SPA) expense tracker designed with modern glassmorphism aesthetics.

## ✨ Key Features
- **Aesthetic Design:** Sleek light/dark modes with dynamic humanist layouts.
- **Smart Tracking:** Easily add transactions and view real-time balance calculations.
- **Visual Analytics:** Interactive doughnut charts powered by Chart.js.
- **Savings Goals:** Configure custom goals, track targets, and monitor dynamic progress rings.
- **Responsive Layout:** Optimized for desktop sidebar workflows and mobile bottom-nav layouts.

## 🚀 Getting Started
Simply open `index.html` in any browser, or host it locally:
```bash
python -m http.server 8080
```
Then visit: `http://localhost:8080`
